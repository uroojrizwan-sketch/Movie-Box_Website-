## 🎥 About The Project

**Movie Zone** is a movie browsing website that displays a collection of movies with their posters, titles, and ratings.

Users can explore movies by selecting different genre categories, making it easier to browse movies according to their interests.

This project was built to practice JavaScript DOM manipulation, array methods, event handling, and responsive web design.

## ✨ Features

- 🎬 **Movie Collection:** Displays a collection of movies using dynamically generated HTML.
- 🗂️ **Genre Filtering:** Filter movies by different categories.
- ⭐ **Movie Ratings:** Displays ratings alongside movie titles.
- 🖼️ **Movie Posters:** Shows movie poster images.
- 🎨 **Dark UI:** Black background with a yellow-accented movie-themed design.
- 🖱️ **Interactive Filters:** Category buttons update the displayed movie collection.
- 📱 **Responsive Layout:** CSS media queries adjust the layout for smaller screens.
- ✨ **Hover Effects:** Movie posters have a smooth hover animation.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/uroojrizwan-sketch/Movie-Box_Website-.git
```

**2. Open the project folder**

```bash
cd Movie-Box_Website-
```

**3. Open the HTML file**

Navigate to the `Movie Box Using JS` folder and open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
